Attention Atlas is a visual tool for inspecting how transformer models route
information - surfacing per-head attention patterns, token focus, and how
behavior shifts layer by layer.

Load a sequence and step through the layers to see which tokens each head
attends to, compare heads side by side, and build intuition for the structures
that emerge inside a trained model.
